# Калькулятор Панкиль

Модифицированный калькулятор для сейфа в мобильной игре **Слово за Слово**.

Считает, как добрать нужное количество очков **за два хода** — подбирает пары множителей (КМ) и количество очков за ход так, чтобы попасть в цель точно.

**Сайт:** https://itzyakutia.github.io/Pankil/

## Что умеет

- **Несколько аккаунтов** — у каждого своё название, свои множители, свои бонусы и очки. Переключение вкладками сверху.
- **Точный подбор за два хода** — решает уравнение `КМ₁ × x + КМ₂ × y = цель` в целых числах. Если точного попадания нет, считает **минимально возможное** превышение для каждой пары множителей и показывает ближайшие варианты.
- **Бонус от рекламы** — прибавляется к КМ. Вкладка «Без рекламы» показывает решения, которые обходятся без него.
- **Грааль** — процент к КМ без рекламы, бонус рекламы прибавляется уже сверху. Округление обычное, по 0.5.
- **Обмен аккаунтами** — кнопка «Копировать» даёт короткий код `KARAS1:…`, его можно отправить другому игроку, он вставит у себя кнопкой «Вставить». Удобно, когда играешь сейф за кого-то.

Аккаунты и множители хранятся только в браузере игрока (localStorage) и никуда не передаются. На сайте стоит счётчик посещений — он считает заходы, не использует куки и не собирает персональные данные.

## Как устроено

Один файл `index.html` без зависимостей и без сборки — правится и заливается как есть.
